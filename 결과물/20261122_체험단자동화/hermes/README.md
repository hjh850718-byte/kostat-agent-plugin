# 헤르메스 등록 방법

## 1. 스킬 복사
`review-trial-routine/` 폴더를 헤르메스 스킬 폴더에 통째로 복사.
- 기본 경로(확인 필요): `~/.hermes/skills/productivity/review-trial-routine/SKILL.md`
- 복사 후 헤르메스에서 "스킬 목록 보여줘"로 `review-trial-routine`이 보이는지 확인.

## 2. 예약 등록 (헤르메스 채팅에 그대로 입력)
```
review-trial-routine 스킬로 아래 예약 작업 5개를 만들어줘. 모두 scan 모드, 제출 금지.
1) 매일 09:00 — 3.1 네이버 무료체험 scan
2) 월·수·금 09:10 — 3.3 무신사 scan + 상위 3건 draft
3) 화·목 09:20 — 3.4 블로그 체험단(배송형) scan
4) 매월 1일 09:30 — 3.2 한달사용리뷰 점검
5) 매주 일 21:00 — 주간 리포트 (state.json·logs만, 브라우저 미사용)
결과는 나에게 요약으로 보내고, 등록된 예약 목록과 다음 실행 시각을 표로 보여줘.
```

## 3. 첫 실행 전 확인
- [ ] 헤르메스 브라우저가 네이버·무신사·서울오빠에 로그인된 프로필을 쓰는지 (헤드리스·클라우드 브라우저는 무신사 Cloudflare 차단 가능성 높음)
- [ ] 노션 연결 여부 (없으면 결과는 logs에만 저장)
- [ ] 서울오빠 마이페이지 '추가 정보' 1회 등록
- [ ] 방문형 포함 여부 결정 → SKILL.md 1.2 `include_visit_type`

## 미검증
- 헤르메스 스킬 폴더 경로·frontmatter 필드(`version`, `metadata.hermes`)는 공개 SKILL.md 형식 기준으로 작성. 버전에 따라 다를 수 있음.
