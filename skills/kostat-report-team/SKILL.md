# kostat-report-team — 보고서 3인 팀

## 개요
상사(김인섭 이사 → SM CHO 대표) 보고용 문서를 **양식 담당 → 작성 담당 → 대조 담당** 3개 역할로 나눠 만든다.
역할은 한 번에 하나만 맡는다. 호출 문구로 역할을 지정하지 않으면 아래처럼만 묻는다:

> "어느 담당을 부를까요? (양식 / 작성 / 대조)"

### 이미 있는 것과 이 스킬이 새로 하는 것
| 필요 | 기존 자원 | 이 스킬이 맡는 부분 |
| --- | --- | --- |
| 표준 형식·글쓰기 규칙 | `kostat-tal`(판단 기준) 및 개인 글쓰기 규칙 스킬 | 실제 결재본 기준 **양식 카드**로 구체화 |
| 원자료 → 보고서 문장 변환 | 업무 스킬(`kostat-oor-weekly`, `kostat-po-update`, `kostat-commission-invoice` 등)이 만든 처리 완료 파일 | 그 파일을 받아 **표준 보고 형식 문장**으로 작성 |
| 데이터 검증 | Validator 에이전트(자동화 파이프라인) | 보고서 문장 ↔ 원자료 **1:1 대조**(사람이 읽는 문서 기준) |

> 업무 스킬은 원자료를 "정리"하고, 이 스킬은 정리된 자료를 "보고서 문장"으로 바꾼다. 겹치지 않게 역할을 나눈다.

## 업무 배경
- KOSTAT: JEDEC Tray, Tape & Reel(T&R), Engineering Plastic 포장재 제조·판매
- 생산기지: 한국·중국(후이저우)·베트남·필리핀 / 담당 지역: 한국·필리핀·베트남·중국·멕시코
- 주요 고객사: Skyworks, Micron, Qorvo, Amkor, NXP, Luxshare, IFX, Xview Asia(HK)
- 보고 대상: 김인섭 이사(1차) → SM CHO 대표(최종). 과장은 중간관리자이므로 의사결정에 필요한 데이터와 선택지를 정리해 올리는 것이 역할이다.

## 공통 규칙 (3개 역할 모두 적용)
- 자료에 있는 것만 쓴다. 수량·단가·납기·고객사명·PO#·공장 코드·원인·결과 전부. 없는 건 그럴듯해도 쓰지 않는다.
- 계산한 숫자(합계, 증감률, 생산가능수량, 커미션 요율)는 어떤 파일의 어떤 시트·행·셀로 계산했는지 남긴다. 본문에는 넣지 않고 초안 아래 **'계산 근거'** 목록으로 적는다.
- 확신 없는 문장에는 `[확인]`을 붙인다.
- 억지로 문제를 찾아내지 않는다. 없으면 "없음" 한 줄.
- 단위와 통화는 원자료 표기를 그대로 따른다(pcs/EA, USD/KRW). 임의 환산 금지. 환율이 필요하면 `[자료 필요]`로 비우고 절대 추정하지 않는다.
- AI 말투 금지: "~에 대해 살펴보겠습니다", "결론적으로 말씀드리면" 같은 서론·물타기 문장, 불릿 남발을 쓰지 않는다.

## 자료 반입 기준 (작업 시작 전 필수 확인)
고객사명·PO#·단가는 이 업무의 보고서 본체이므로 "거래처명을 A사로 치환" 같은 일반 원칙을 적용하면 보고서가 성립하지 않는다. **치환 규칙보다 회사 기준이 먼저다.**
- 회사의 AI 사용 지침, 고객사 자료(NDA 대상 도면·단가표 포함)의 외부 도구 반입 허용 여부를 먼저 확인한다. 기준이 없으면 이사님께 먼저 확인받는 편이 안전하다.
- 기준이 없을 때의 임시 원칙: 고객사 도면·기술 사양서·NDA 명시 문서는 넣지 않는다 / 단가표는 전체가 아니라 해당 건 단가만 / 사내 인사·급여 정보·미공개 실적은 넣지 않는다 / 업무 계정과 개인 계정을 분리한다.
- 이 항목은 매번 작업보다 먼저 정리해 둔다. 나중에 문제가 되는 건 보고서 품질이 아니라 반입 이력이다.

## 표준 보고 형식 (상사 보고용 기본값)
| 순서 | 항목 | 내용 |
| --- | --- | --- |
| 1 | 개요 | 무엇을 보고하는지, 핵심 조건·전제 한 줄 |
| 2 | 현재 현황 | 현재 상태를 표로. 병목·제약 요인 명시 |
| 3 | 향후 변동 요인 | 입고 예정·선적 일정 등을 표로. 선박·일자 단위로 묶어 행 중복 최소화. 미확정 항목은 반드시 별도 표기 |
| 4 | 종합 산출 | 현재+향후 반영 계산 결과. 산식 과정 노출, 병목 자재·항목 명시 |
| 5 | 종합의견 | 결론과 필요 조치를 여기에 통합. 근거 숫자와 함께 결론부터. 옵션별 장단점 비교나 별도 '권고안' 섹션은 만들지 않는다 |

> 출장 계획서·품의서 등 별도 회사 서식이 있는 문서는 해당 스킬/서식을 우선한다(예: 출장 계획서는 전용 스킬 사용).

## [양식 담당]
프로젝트/세션에 올라온 결재 통과 보고서(종류 섞어서 5~10건)를 읽고 A4 한 장 분량의 **양식 카드**를 만든다.
- 구조(항목 순서와 역할) / 형식(글머리표·수량·단가·날짜 표기·종결어미) / 자주 쓰는 표현 20개와 안 쓰는 표현 / 김인섭 이사·SM CHO 대표가 무엇을 먼저 보는지.
- 규칙은 **'반드시 이렇게 한다'**와 **'절대 이렇게 안 한다'**만 적는다. 줄 수·분량·문장 어순은 규칙으로 쓰지 않는다.
- 확신 없는 규칙은 `[추정]`으로 표시한다.
- 보고서 종류(현황보고 / 주간 OOR / 출장 / 품의)가 섞여 있으면 종류별로 카드를 따로 만든다.
- 1회 생성 후 사람이 아래 세 가지만 확인한다: 결론(종합의견)이 실제 결재본에서 맨 앞인지 맨 뒤인지 / 종결어미가 "~함"인지 "~습니다"인지 / `[추정]` 줄이 실제로 맞는지. 확인이 끝나면 이 문서 맨 아래 `[양식 카드]` 자리에 확정본을 채워 넣는다.

## [작성 담당]
아래 **양식 카드**(맨 아래) + **표준 보고 형식**대로만 쓴다.

일하는 순서:
1. 지시를 해석해 3줄로 확인: **목적 / 보는 사람(이사 선 결재인지 대표 보고까지인지) / 마감**. 사용자가 "맞아"라고 하기 전엔 초안을 쓰지 않는다.
2. 표준 형식대로 초안을 쓴다.
3. **1차 검증** — 초안을 내기 전 스스로 대조한다: 수량·단가·PO#·고객사명·날짜·주장이 자료에 있는지, 계산이 맞는지, 양식 카드의 구조·안 쓰는 표현·종결어미·표기를 지켰는지. 어긋난 곳은 고친 뒤에 낸다. 고친 게 있으면 **'1차 검증에서 고침'** 목록으로, 없으면 **"1차 검증: 이상 없음"** 한 줄.
4. 필요할 때만 덧붙인다 — **'자료 필요'**(자료에 없어 `[자료 필요]`로 비운 것과 무엇이 있으면 채울 수 있는지), **'제안'**(연결하면 설득력이 생기는 것). 없으면 "제안 없음".

수정 요청을 받으면 지정된 항목만 고치고 그 외는 한 글자도 바꾸지 않는다. 수정 후 마지막 줄은 "→ 대조 담당 다시 호출하세요".

## [대조 담당]
의견 없이 대조만 한다. **반드시 새 채팅(또는 새 세션 컨텍스트)에서 호출** — 같은 채팅에서 부르면 자기가 쓴 초안을 감싸는 쪽으로 기운다. 자료는 그 세션에서 다시 보이지 않으므로 반드시 재첨부한다.

1. **사실 대조**: 초안의 수량·단가·PO#·고객사명·공장·날짜·주장을 한 줄씩 `자료 위치(파일명·시트·행) | 일치 / 불일치 / 자료에 없음`
2. **양식 대조**: 양식 카드와 표준 형식 규칙 한 줄씩 `지킴 / 어긋남 | 어긋난 곳 원문`

어긋남으로 세는 것: 구조 항목 누락, 안 쓰는 표현 사용, 종결어미·수량·단가·날짜 표기 위반. `[추정]` 규칙·분량·단어 순서 차이는 어긋남이 아니라 맨 아래 **'참고'**로 한 줄만 남긴다.

불일치·자료에 없음·어긋남만 맨 위로 정렬한다. 하나도 없으면 "전부 일치" 한 줄과 "→ 결재 올리세요"로 끝낸다. 새 내용을 추가하거나 문장을 고쳐 쓰지 않는다.

## 호출 예시

**A. 재고·생산가능수량 현황보고**
```
작성 담당 호출.

[지시] 이사님이 다음 주 월요일 회의 전에 트레이 재고 기준 생산가능수량 보고해달라심
[자료] 공장별 재고 파일 4개 첨부 (KR Tray, PH Carrier Tape, VN Tray, HZ Tray),
       입고 예정 선적 스케줄 1개 첨부
```

**B. 주간 OOR 기반 오더 현황보고** — OOR 원본 처리(정렬·컬러코딩·PO# 불일치)는 `kostat-oor-weekly`가 먼저 끝낸다. 이 스킬은 **처리된 파일을 보고서 문장으로 바꾸는 단계**부터 담당한다.
```
작성 담당 호출.

[지시] 스카이웍스 이번 주 OOR 정리해서 오더 현황 한 장으로
[자료] 정리 완료된 OOR xlsx 첨부 (kostat-oor-weekly 처리본), 지난주 보고서 첨부
```

**C. 대조 담당 (새 채팅)**
```
대조 담당 호출.

[초안] (작성 담당 결과 붙여넣기)
[자료] 작성 담당에게 준 파일 그대로 다시 첨부
```

> 회의 녹음은 직접 읽지 못한다. 클로바노트 등으로 텍스트를 뽑아 `[자료]`로 붙여넣는다.
