# kostat-kakao-export-search

## 개요
Windows 카카오톡 PC 클라이언트의 **대화 내보내기** 기능으로 저장한 txt 파일을 로컬에서
검색하는 스킬입니다. `kostat-katok-search`(katok CLI, Apple Silicon macOS 전용)와 달리
별도 프로그램 설치 없이 Claude Code 기본 도구(Read/Grep/Glob)만으로 동작하며, 이 플러그인의
기본 작업 환경인 Windows에서 바로 쓸 수 있습니다.

동기화가 자동이 아니라 **사용자가 내보내기를 다시 실행해야 최신화**된다는 점,
벡터 기반 semantic 검색이 없다는 점이 katok과의 핵심 차이입니다. 아래 "한계" 표를 참고하세요.

## 사전 준비 (사용자 수동 작업, 1회 또는 필요 시마다)
1. 카카오톡 PC에서 검색할 대화방을 연다.
2. 대화방 우측 상단 메뉴(≡) → **대화 내보내기** → 텍스트로 저장(옵션에 따라 사진 포함 여부 선택 가능하나, 이 스킬은 텍스트만 다룬다).
3. 저장된 `.txt` 파일을 지정 폴더에 모은다. 기본값:
   `C:\Users\USER\Desktop\77. CLOUDE 정리용\카카오톡 내보내기\`
4. 카카오톡이 자동 생성하는 파일명을 그대로 써도 되지만, 여러 방을 구분하려면 앞에 고객사명을
   붙여 리네임하는 것을 권장한다 (예: `Skyworks_KakaoTalkChats_20260809.txt`).
5. 이 폴더는 **git 저장소 밖**에 둔다. 절대 커밋 대상이 아니다.

## 내보내기 파일 포맷 (참고)
카카오톡 대화 내보내기 텍스트는 대략 아래 형식이다.

```
2026-08-09 09:15, 홍길동 : 이번 주 PO 확인 부탁드립니다
2026-08-09 09:16, 한준희 : 네 확인하겠습니다
2026-08-09 09:20, 홍길동 님이 들어왔습니다.
```

- 일반 메시지: `날짜 시각, 발신자 : 메시지`
- 시스템 메시지(입장/퇴장 등): `" : "` 구분자가 없는 문장형 — 검색 결과에서 제외한다.
- 사진·이모티콘·파일 첨부는 텍스트로만 표시("사진", "이모티콘", "파일: ...")되고 실제 파일은
  포함되지 않는다.

## 검색 절차
1. **대상 파일 확인** — 지정 폴더에서 Glob으로 사용자가 말한 고객사/방 이름에 해당하는
   `.txt` 파일을 찾는다. 여러 개면 파일명·수정일 기준 최신 것을 우선한다.
2. **freshness 확인** — 파일의 마지막 수정일을 확인한다. 7일 이상 지났으면 "최신 대화가
   아닐 수 있다"고 안내하고, 최신 대화가 중요하면 재내보내기를 요청한다. 자동 동기화가
   없으므로 이 확인을 생략하지 않는다.
3. **검색 실행** — Grep으로 키워드를 찾는다. 여러 키워드·의미 기반 질의는 파일 내용을 훑어
   Claude가 직접 판단한다(별도 벡터 인덱스 없음).
4. **시스템 메시지 필터링** — `" : "`가 없는 줄(입장/퇴장/초대 등)은 결과에서 제외한다.
5. **결과 요약** — 기본은 매칭된 줄의 날짜·발신자·앞뒤 1~2줄 스니펫만 보여준다. 대화 원문
   전체를 그대로 dump하지 않는다.
6. **원문 확인** — 사용자가 "전체로 보여줘", "그 앞뒤로 더 보여줘" 등 명시적으로 요청할 때만
   해당 구간 전체를 보여준다.

## Privacy Rules
- 카카오톡 내보내기 폴더 경로와 내용은 **git 저장소 밖에 둔다**. 이 스킬이 그 폴더를 참조는
  하되, 폴더 자체나 그 안의 파일을 저장소에 추가하도록 안내하지 않는다.
- 실제 대화에서 확인한 내용(인용문, 상대방 이름, 방 이름 등)은 스킬 파일·커밋 메시지·문서·
  테스트 어디에도 기록하지 않는다. 세션 내 답변에만 사용한다.
- 검색 결과는 기본적으로 스니펫만 보여주고, 전체 원문은 명시적 요청 시에만 노출한다.
- 내보내기 폴더가 클라우드 동기화 폴더(OneDrive 등) 하위에 있으면, 그 자체가 민감정보 노출
  경로가 될 수 있음을 사용자에게 1회 안내한다.
- 이 스킬에는 메시지 전송 기능이 없다. 내보내기는 읽기 전용 파일이므로 전송 경로 자체가
  존재하지 않는다.

## 한계 (katok 대비)

| 항목 | kostat-katok-search (Mac) | 이 스킬 (Windows 내보내기) |
|------|---------------------------|------------------------------|
| 동기화 | 증분 자동 sync | 사용자가 수동으로 재내보내기 |
| 검색 방식 | keyword / BM25 / semantic 벡터 | 키워드·문맥 기반 (Claude가 직접 훑음) |
| 미디어 첨부 | 사진·영상·파일 추출 가능 | 텍스트만 (내보내기 옵션에 따라 다름) |
| 실시간성 | 마지막 sync 시점까지 | 마지막 내보내기 시점까지 |
| 설치 요구사항 | katok CLI 별도 설치 (Apple Silicon macOS) | 불필요 — Claude Code 기본 도구만 |

## 검증 체크리스트 (Loop 방식)
- [ ] 대상 파일이 사용자가 말한 고객사/방과 정확히 일치하는지 확인
- [ ] freshness(마지막 내보내기 시각)를 확인하고 필요 시 재내보내기 안내했는지 확인
- [ ] 시스템 메시지(입장/퇴장 등)를 결과에서 걸러냈는지 확인
- [ ] 검색 결과를 스니펫 수준으로만 요약했는지 확인 (전체 원문 무단 노출 금지)
- [ ] 실제 대화 내용이 스킬 산출물(커밋, 문서, 로그)에 남지 않았는지 확인

## 검증 루프 절차
1. **체크리스트 1회 실행** — 위 항목 순차 점검
2. **실패 항목 발견 시** → 원인 재확인 → 재시도 → 다시 1단계로 (Loop)
3. **전체 통과 시** → 결과 요약 출력

### Loop 규칙
- 실패가 0이 될 때까지 반복 (최대 3회)
- 3회 초과 실패 → 사용자에게 상황 보고 후 에스컬레이션 (예: 파일을 못 찾음, 포맷이 다름)

## Field Notes
- 내보내기 파일 인코딩은 UTF-8 또는 UTF-8 BOM일 수 있다. 읽기 오류가 나면 인코딩 문제일
  가능성을 먼저 의심한다.
- 대화방 인원이 많거나 기간이 길면 파일이 커질 수 있으므로, 전체를 Read하기보다 Grep으로
  먼저 좁히는 것이 효율적이다.
- 같은 방을 여러 번 내보내면 겹치는 구간이 생길 수 있다. 최신 파일을 우선하고, 필요하면
  사용자에게 어느 파일 기준인지 명시한다.

## 관련 스킬
- `kostat-katok-search` — 같은 목적(고객사 카카오톡 대화 로컬 검색)이지만 Apple Silicon
  macOS + katok CLI 전용. Mac 환경이 준비되면 그쪽이 동기화·semantic 검색 등 더 강력하다.
- 기존 `kostat-morning-briefing`의 "KakaoTalk (MCP)"는 PlayMCP를 통한 **발송**용이며, 이
  스킬과는 무관하다.
