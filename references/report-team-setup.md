# kostat-report-team — 세팅 · 파일 배치 · 체크리스트

`kostat-report-team` 스킬 본문(SKILL.md)에서 참조하는 상세 자료. 토큰 절감을 위해 분리했다.

## 1. 최초 세팅 (1회)

1. **양식 카드 재료 준비** — 결재 통과한 보고서 5~10건을 종류 섞어서 준비한다(현황보고, 주간 OOR 보고, 출장 계획서/보고서, 품의서). 전자결재함에서 "내 기안 → 결재 완료"로 필터링해 내려받으면 빠르다.
2. **넣으면 안 되는 것** — 이번 주 OOR xlsx, 이번 달 PO 리스트, 재고 현황 파일처럼 매번 바뀌는 자료는 양식 카드 재료에 섞지 않는다. 다음 달 보고서에 지난달 숫자가 섞이는 원인이 된다. 변동 자료는 항상 그 작업 세션에만 첨부한다.
3. **양식 카드 1회 생성** — `양식 담당 호출.`로 카드를 만든 뒤 사람이 확인:
   - 결론(종합의견)이 실제 결재본에서 맨 앞/맨 뒤 어디에 오는가
   - 종결어미가 "~함"인지 "~습니다"인지
   - `[추정]` 붙은 줄이 실제로 맞는가
   확인이 끝나면 SKILL.md 맨 아래 `[양식 카드]` 자리에 확정본을 채워 넣는다.

## 2. 파일 배치 규칙

| 위치 | 넣는 것 | 비고 |
| --- | --- | --- |
| 고정 자료(양식 카드 재료) | 결재 통과 보고서 5~10건 | 전자결재함 다운로드분, 최초 세팅 시 1회만 |
| 매 작업 첨부 | OOR xlsx, PO 리스트, 재고 파일, 커미션 RAW DATA, 회의 녹취록 텍스트 | 그때그때 첨부, 고정 자료에 섞지 않는다 |

회의 녹음은 텍스트가 아니므로 직접 읽지 못한다. 클로바노트 등으로 텍스트를 뽑아 붙여넣는다.

## 3. 첫 한 건 체크리스트

1. `작성 담당 호출.` + `[지시]` + `[자료]` 첨부 → **목적/보는 사람/마감 3줄**이 오면 정상
2. "맞아" → 초안 + "1차 검증: 이상 없음"(또는 고침 목록)
3. 초안에서 `[자료 필요]`·`[확인]`만 채우거나 삭제 → 대괄호가 하나도 안 남으면 다음
4. **새 채팅/세션**에서 `대조 담당 호출.` + 초안 + 같은 자료 재첨부 → '자료에 없음'만 사람이 판단
5. 대조표를 작성 담당 쪽에 넘겨 수정 → 대조 한 번 더 → "전부 일치"면 결재 상신

첫 주에는 한 건만 진행한다. 정형 보고(예: 재고 기준 생산가능수량 현황보고)부터 시작하면 양식 카드 검증이 함께 된다.

## 4. 한글(.hwp)로 옮기기

1. 회사 서식 파일을 연다.
2. 본문은 **텍스트만 붙여넣기**(Ctrl+Alt+V) — 서식 파일의 폰트·줄간격을 그대로 물려받는다.
3. 표는 채팅에서 통째로 붙이지 말고, 서식 파일의 빈 표에 **값만** 붙여넣는다.

양식 카드는 글의 모양, 서식 파일은 파일의 모양 — 역할이 다르다.
