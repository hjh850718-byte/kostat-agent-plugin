# 출력 계약 (모든 KOSTAT 스킬 공통)

REA의 Evidence 구분(관찰/유도/추론/미확인)을 영업 업무에 맞게 적용한 규칙.

| 라벨 | 의미 | 예시 |
|------|------|------|
| 확인됨 | 원본 문서에 그대로 존재 | PO PDF의 PO#, 수량, 단가 |
| 계산됨 | 확인된 값에서 수식으로 도출 | 커미션 = 금액 × 요율, 요율 역산 |
| 추정 | 근거는 있으나 원본에 없음 | 누락된 납기를 과거 리드타임으로 추정 |
| 미확인 | 알 수 없음 | PDF 추출 실패 필드 |

## 규칙
1. 결과 보고에 `확인됨/계산됨/추정/미확인` 건수를 한 줄로 요약한다.
2. `추정`·`미확인` 값은 Excel에 쓰지 않고 사용자 확인 후 입력한다.
3. 식별 불확실(고객사·PO#·금액·납기) 시 중단하고 질문한다 (fail-closed).
4. 쓰기 전 변경 계획(파일, 시트, 행, 값)을 표로 제시하고 승인받는다.
5. 동일 PO# 재처리 시 기존 행을 갱신하며 중복 행을 만들지 않는다.
6. 처리 결과에는 원본 파일명과 처리 시각을 남긴다.
