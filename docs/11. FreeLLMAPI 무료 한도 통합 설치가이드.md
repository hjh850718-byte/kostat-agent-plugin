# FreeLLMAPI 무료 한도 통합 설치가이드

> 비전문가 일반인 기준으로 순서대로 적었습니다. 터미널(검은 창) 열 일 없습니다.
> 보수적으로 월 30만원이라고 적었는데 실제로는 더 클 겁니다.

## 이게 뭔가요

AI 회사마다 매달 공짜로 쓸 수 있는 양이 정해져 있습니다. 개발자들이 자기 서비스로
뭔가 만들어보라고 열어둔 몫입니다. 그런데 한 곳만 붙잡고 쓰면 반나절이면 바닥나서,
결국 다들 돈을 내게 됩니다.

FreeLLMAPI는 여기저기 흩어진 그 무료 계정들을 내 컴퓨터 안에서 하나로 묶어주는
프로그램입니다. 한 곳이 막히면 알아서 다음 회사로 넘겨 답을 이어받고, 어디가 얼마나
남았는지도 한 화면에 보여줍니다.

만든 사람이 무료로 공개했고 광고나 결제창이 없습니다. 무드모드가 만든 도구가 아니며,
설치 방법만 초보자 기준으로 정리한 페이지입니다.

원본: github.com/tashfeenahmed/freellmapi

## 먼저 알아두실 것

개인이 혼자 쓰는 용도입니다. 회사 서비스나 파는 제품에 붙이는 건 만든 사람이 직접
하지 말라고 못을 박아뒀습니다.

시작하기 전에 이건 알고 가시는 게 좋습니다.

| 항목 | 실제로는 |
|------|----------|
| 성능 | 클로드 하이쿠 정도라고 보시면 됩니다. 오퍼스처럼 제일 비싼 모델은 애초에 공짜로 푸는 곳이 없습니다 |
| 시간대 | 저녁으로 갈수록 좋은 모델부터 한도가 차서 답이 조금 떨어집니다. 매일 아침 9시에 다시 채워집니다 |
| 규모 | 한국에서 가입되는 곳 대여섯 군데만 넣어도 한 달에 2억에서 4억 토큰이 나옵니다. 돈으로 치면 보수적으로 40~50만원어치쯤 됩니다 |
| 74억 토큰 | 깃허브에 적힌 숫자입니다. 34곳을 하나도 빠짐없이 다 넣었다고 치고 더한 값이라, 실제로는 이만큼 안 나옵니다 |

번역이나 요약, 초안 잡기 같은 잡일을 여기로 넘긴다고 생각하시면 됩니다. 진짜 중요한
작업은 지금 쓰시는 유료 그대로 두세요.

## 1단계 · 앱 받기

아래 주소로 들어갑니다.

https://github.com/tashfeenahmed/freellmapi/releases/latest

Assets 목록을 펼치면 파일이 열 개 넘게 나옵니다. 겁먹지 마시고 내 컴퓨터에 맞는 것
하나만 받으면 됩니다. 아래는 2026년 8월 기준 최신인 v0.9.0의 파일 이름입니다. 버전이
올라가면 숫자만 바뀝니다.

| 내 기기 | 받을 파일 |
|---------|-----------|
| 윈도우 (대부분 여기) | Releases 페이지의 `.exe` 설치 파일 |
| 맥 M1, M2, M3, M4 (2020년 이후) | Releases 페이지의 Apple Silicon용 `.dmg` |
| 안드로이드 폰 | 구글 플레이에서 FreeLLMAPI 검색 |

내 맥이 어느 쪽인지 모르겠으면 화면 왼쪽 위 사과 아이콘을 누르고 "이 Mac에 관하여"를
열어보세요. 칩 항목이 Apple M으로 시작하면 위 파일을 받으시면 됩니다. Intel이라고
적혀 있으면 맞는 설치 파일이 아직 없습니다.

받으면 안 되는 것: `.blockmap`, `.yml`/`.yaml` 업데이트 메타파일, 소스 코드
(zip/tar.gz), `.AppImage`/`.deb`(리눅스용). 순서대로 업데이트용 부속 파일, 개발자용
원본 코드, 리눅스용입니다.

## 2단계 · 설치하고 처음 켜기

### 윈도우

1. 받은 `.exe`를 두 번 클릭합니다
2. "Windows가 PC를 보호했습니다" 경고가 뜨면 추가 정보를 누르고 실행을 선택하세요.
   서명 비용을 안 들인 무료 오픈소스라 뜨는 경고입니다
3. 설치가 끝나면 화면 오른쪽 아래 작업표시줄에 아이콘이 생깁니다

### 맥

1. 받은 `.dmg`를 두 번 클릭하고, 나온 앱을 응용 프로그램 폴더로 옮깁니다
2. 처음 켤 때는 두 번 클릭 말고 우클릭 후 열기를 누르세요. 그냥 두 번 클릭하면
   "확인되지 않은 개발자" 경고에 막힙니다
3. 화면 맨 위 메뉴바에 아이콘이 생깁니다

### 관리 화면 열기

아이콘을 누르고 Open Dashboard를 선택하면 관리 화면이 브라우저에 열립니다. 비밀번호는
없습니다. 만들 것도 없고 잊어버릴 것도 없습니다.

화면이 영어면 오른쪽 위 ⋯ → Settings에서 언어를 한국어로 바꾸세요. 60개 언어를
지원합니다.

## 3단계 · 무료 열쇠 받기

여기가 유일하게 손이 가는 단계입니다. 회사마다 가입해서 열쇠(API 키)를 받아
붙여넣으면 됩니다. 전부 무료고 카드 등록도 없습니다.

여섯 곳을 다 하실 필요 없습니다. 위에서부터 세 곳만 하세요. 5분이면 끝나고 혼자
쓰기에는 그걸로 충분합니다. 나중에 부족하다 싶을 때 아래쪽을 하나씩 늘리시면 됩니다.

### 어느 것부터 할까요

| 순서 | 회사 | 시간 | 난이도 | 이 회사를 넣는 이유 |
|------|------|------|--------|----------------------|
| 1 | 구글 AI Studio | 1분 | 쉬움 | 구글 계정만 있으면 클릭 세 번이면 끝납니다. 제미나이 모델을 씁니다 |
| 2 | Groq | 2분 | 쉬움 | 답이 튀어나오는 속도가 압도적입니다. 여기 하나로 체감이 확 달라집니다 |
| 3 | Cerebras | 2분 | 쉬움 | 무료로 주는 양이 넉넉하고 역시 빠릅니다 |
| 4 | NVIDIA | 5분 | 보통 | 고를 수 있는 모델 종류가 제일 많습니다. 계정을 새로 만들어야 합니다 |
| 5 | OpenRouter | 3분 | 보통 | 여러 회사 모델을 계정 하나로 씁니다. 대신 무료 한도가 빡빡합니다 |
| 6 | Cloudflare | 10분 | 어려움 | 넣을 게 두 개라 번거롭습니다. 처음이면 건너뛰셔도 됩니다 |

### 공통 주의사항 세 가지

- 열쇠는 만든 직후에 딱 한 번만 보여주는 곳이 많습니다. 창을 닫기 전에 메모장에
  붙여두세요.
- 영어 화면에서 막히면 크롬에서 마우스 우클릭 후 한국어로 번역을 누르면 전부 한글로
  바뀝니다.
- 카드 번호를 요구하는 화면이 나오면 그 회사는 건너뛰세요. 아래 여섯 곳은 카드 없이
  됩니다.

1. 구글 AI Studio
2. Groq
3. Cerebras
4. NVIDIA
5. OpenRouter
6. Cloudflare

### 받은 열쇠 넣기

1. 관리 화면에서 Keys 탭을 누릅니다
2. 오른쪽 위 + Add key를 누릅니다
3. 회사를 고르고, 복사해둔 열쇠를 붙여넣습니다
4. 목록에 초록 점이 뜨면 정상입니다. 빨간 점이면 열쇠를 잘못 복사한 겁니다. 앞뒤에
   공백이 딸려왔거나 일부만 복사된 경우가 대부분이니 지우고 다시 붙여넣으세요

## 4단계 · 바로 써보기

가장 쉬운 방법은 이 앱 안에서 바로 쓰는 것입니다. 다른 프로그램을 깔 필요가
없습니다.

1. 관리 화면에서 Playground 탭을 누릅니다
2. 아래 입력창에 질문을 쓰고 엔터를 칩니다
3. 답 위에 어느 회사가 처리했는지, 몇 초 걸렸는지가 같이 표시됩니다

이미지나 텍스트 파일을 끌어다 놓으면 그것도 같이 읽습니다. 번역, 요약, 초안 잡기 같은
일은 여기서 다 됩니다.

여기까지만 하셔도 충분합니다. 다음 단계는 코딩 도구를 쓰시는 분만 보시면 됩니다.

## 5단계 · 쓰던 앱에 연결하기 (선택)

커서나 클로드 코드 같은 도구를 쓰고 계시면 거기에 물릴 수 있습니다.

먼저 통합 열쇠를 복사합니다. Keys 페이지 맨 위에 있습니다. 앞으로 쓸 열쇠는 이것
하나뿐이고, 회사별 열쇠는 다시 꺼낼 일이 없습니다.

- 주소(Base URL): 대시보드 Keys 페이지에 표시되는 로컬 주소
- 열쇠(API Key): 방금 복사한 통합 열쇠

이 두 개를 앱 설정의 해당 칸에 넣으면 끝입니다. 커서, 클라인, Continue, Zed,
젯브레인 AI 전부 같은 방식입니다.

클로드 코드만 주소가 다릅니다. 뒤에 붙는 경로를 붙이지 않고 대시보드에 표시된
기본 주소까지만 씁니다.

## 막혔을 때

| 상황 | 이렇게 하세요 |
|------|----------------|
| 답이 안 옵니다 | 앱이 켜져 있는지 먼저 보세요. 내 컴퓨터에서 도는 프로그램이라 앱을 끄면 연결한 다른 앱도 같이 멈춥니다 |
| 열쇠에 빨간 점이 떴어요 | 앞뒤에 공백이 붙었거나 일부만 복사된 경우가 대부분입니다. 지우고 다시 붙여넣으세요 |
| 열쇠를 다시 못 보겠어요 | 그 회사 사이트에서 새로 만드시면 됩니다. 대부분 여러 개 만들 수 있습니다 |
| 답이 자꾸 이상하게 나옵니다 | Models 탭에서 라우팅 전략을 Smartest로 바꿔보세요. 기본값은 속도와 성능을 섞은 Balanced입니다 |
| 연결한 앱이 못 찾습니다 | 주소 끝에 필요한 경로가 붙었는지 확인하세요. 클로드 코드만 빼고 나머지는 전부 붙습니다 |
| 저녁에 답이 떨어집니다 | 고장이 아닙니다. 좋은 모델부터 그날 한도가 차기 때문이고, 아침 9시에 다시 채워집니다 |
| 화면이 영어라 못 읽겠어요 | 오른쪽 위 ⋯ → Settings에서 한국어로 바꾸거나, 크롬 우클릭 후 한국어로 번역을 누르세요 |

## 자주 묻는 것

**정말 공짜인가요**
프로그램은 무료입니다. 회사별 무료 한도도 원래 공개된 것이라 돈이 나가지 않습니다.
깃허브에 유료 옵션이 하나 보이는데, 새 모델 목록을 매일 받아보는 기능입니다. 안 사도
쓰는 데 지장 없고 새 모델이 30일 늦게 들어올 뿐입니다.

**내 대화는 어디로 가나요**
프로그램은 내 컴퓨터에서 돌고 열쇠도 암호화해서 그 안에만 저장됩니다. 다만 질문
자체는 결국 구글이나 Groq 같은 AI 회사로 갑니다. 중간에 낀 업체가 없다는 뜻이지,
아무 데도 안 간다는 뜻은 아닙니다.

**회사 자료를 넣어도 되나요**
권하지 않습니다. 무료로 여는 대신 입력한 내용을 학습에 쓸 수 있다고 약관에 적어둔
회사가 있습니다. 개인 작업이나 공개해도 되는 자료에만 쓰세요.

**컴퓨터를 계속 켜둬야 하나요**
쓸 때만 켜두시면 됩니다. 앱을 끄면 연결한 앱도 같이 멈춥니다.
