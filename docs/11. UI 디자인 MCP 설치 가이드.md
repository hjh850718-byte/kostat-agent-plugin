# UI 디자인 MCP 설치 가이드

> UI 디자인 MCP 5개(Mobbin·Nicelydone·Refero·Lazyweb·InspoAI)의 설치·활성화 방법.
> 사내 대시보드·제안서 화면 등 UI 작업용 **선택 기능**이며, PO/OOR/커미션 업무와는 무관합니다.
> 모든 수치는 **확인일 2026-10-13 기준**입니다 (화면 수·요금·한도는 서비스 정책에 따라 변동).

---

## 1. 개요 — 5개 MCP 한눈 비교

| 서버 | 용도 | 요금제 | 인증 | 무료 한도 | 연결 방식 |
|---|---|---|---|---|---|
| **Mobbin** | 앱 화면·플로우 레퍼런스 | 유료 (Pro/Team/Enterprise) | OAuth 브라우저 로그인 | 없음 · 60 req/60초 | 원격 http |
| **Nicelydone** | SaaS 플로우·컴포넌트 | 유료 (Paid) | OAuth 2.1 브라우저 로그인 | 미공개 | 원격 http |
| **Refero** | 설계 규칙 (DESIGN.md 생성) | 무료 | 없음 (선택: OpenAI 키) | 카탈로그 ~200개 사이트 | 로컬 npx |
| **Lazyweb** | A/B 근거·디자인 리서치 | 부분 무료 | Bearer 토큰 (무료 발급) | 기본 도구 무료 · 전체 보고서=Pro | 원격 http |
| **InspoAI** | 아이콘 SVG·스크린 | 무료 티어 | API 키 (무료 발급) | 92K+ 스크린 | 로컬 npx |

**5개를 모두 켤 필요는 없습니다.** 필요한 1~2개만 골라 켜세요.

## 2. 상황별 선택 기준

| 이런 일을 할 때 | 추천 서버 |
|---|---|
| 앱 화면(로그인·빈 상태·결제 등) 레퍼런스 | **Mobbin** |
| SaaS 제품 플로우·컴포넌트 라이브러리 | **Nicelydone** |
| 색·타이포·간격 등 설계 규칙, DESIGN.md 생성 | **Refero** |
| A/B 테스트 근거·마케팅 사이트 리서치 | **Lazyweb** |
| 아이콘 검색 + SVG 코드 확보 | **InspoAI** |

## 3. 기본 상태: 전부 비활성

`.mcp.json`의 `mcpServers`에 5개 서버가 정의돼 있지만, `.claude/settings.json`의
`disabledMcpjsonServers` 목록에 모두 등록되어 **기본적으로 비활성**입니다.
유료 계정이 없는 서버가 기본 로드되면 인증 오류가 나기 때문입니다.

### 서버 켜기 (3단계)

1. `.claude/settings.json`의 `disabledMcpjsonServers`에서 **켤 서버 이름을 제거**
2. 토큰/키가 필요한 서버(Lazyweb·InspoAI, Refero는 선택)는 `.env.example`을 `.env`로
   복사해 값을 입력 — 또는 시스템 환경변수로 설정
3. Claude Code 재시작 → `/mcp`에서 서버 상태 확인

```json
// .claude/settings.json 예시 — Lazyweb만 켤 때
{
  "disabledMcpjsonServers": ["mobbin", "nicelydone", "refero", "inspoai"]
}
```

환경변수 설정 (Windows PowerShell):
```powershell
# 시스템에 영구 등록
setx LAZYWEB_MCP_TOKEN "토큰값"
# 또는 현재 세션에만
$env:INSPOAI_API_KEY = "키값"
```

### 연결 확인 방법

- `/mcp` 명령으로 목록에서 서버 상태(enabled/disabled) 확인
- 채팅에서 테스트 요청 (아래 서버별 절차의 예시 프롬프트 복사해서 사용)

## 4. 서버별 설치 절차

### 4.0 OAuth 브라우저 로그인 — 최초 연결 가이드 (Mobbin·Nicelydone 공통)

Mobbin·Nicelydone는 원격 http 서버라 API 키가 없고, **브라우저 기반 OAuth**로 인증합니다.
최초 1회만 하면 되고, 이후에는 자동으로 재사용됩니다.

1. 서버 켜기: `.claude/settings.json`의 `disabledMcpjsonServers`에서 `"mobbin"`(또는 `"nicelydone"`) 제거 → Claude Code 재시작
2. `/mcp`에서 해당 서버가 승인 대기 상태로 표시 → 승인
3. **브라우저가 자동으로 열림** → 유료 플랜 계정으로 로그인 (사용자가 직접)
4. 권한 승인 화면에서 스코프 확인 후 승인 (Nicelydone: `library:read` / `saved:read` / `collections:write`)
5. 승인 완료 → 브라우저를 닫으면 Claude Code가 자동으로 토큰을 받아 시스템 키체인에 저장
6. `/mcp`에서 connected 상태 확인

**브라우저가 열리지 않을 때:**
- Claude Code 재시작 후 `/mcp`에서 해당 서버를 다시 승인
- 기본 브라우저가 설정되어 있는지 확인
- 그래도 안 되면 `.mcp.json`에 OAuth 콜백 포트를 명시 (동적 클라이언트 등록):
```json
{
  "mcpServers": {
    "mobbin": {
      "type": "http",
      "url": "https://api.mobbin.com/mcp",
      "oauth": { "callbackPort": 8080 }
    }
  }
}
```
- 유료 플랜이 아니면 로그인 후에도 도구 호출이 거부됨 (아래 4.1/4.2 요금제 확인)

### 4.1 Mobbin — 앱 화면 레퍼런스 (유료)

1. Mobbin **유료 계정 준비** (Pro 이상 — 무료 플랜은 MCP 미지원)
2. `disabledMcpjsonServers`에서 `"mobbin"` 제거 → 재시작 → 위 [4.0 OAuth 최초 연결](#40-oauth-브라우저-로그인--최초-연결-가이드-mobbinnicelydone-공통) 진행
3. 테스트 요청:
```
Mobbin MCP로 결제(checkout) 화면 예시 3개 검색해줘
```
- 도구(읽기 전용 3종): `search_screens` / `search_flows` / `search_sections`
- 한도: 60 req/60초
- ⚠️ 공식 페이지에 JSON 설정 블록 원문 없음 → 표준 http 형식으로 등록 (OAuth는 최초 연결 시 처리)

### 4.2 Nicelydone — SaaS 플로우 (유료)

1. Nicelydone **유료 계정 준비** (Paid 플랜이 MCP 잠금 해제)
2. `disabledMcpjsonServers`에서 `"nicelydone"` 제거 → 재시작
3. `/mcp`에서 승인 → **브라우저 로그인 (사용자가 직접)**
4. 테스트 요청:
```
Nicelydone에서 SaaS 온보딩 플로우 예시를 검색해줘
```
- 도구 12종(화면·플로우·컴포넌트·앱 검색, 즐겨찾기·컬렉션) — 확인된 도구명 4종:
  `create-collection` / `update-collection` / `add-screens-to-collection` / `send-feedback`
  (나머지 8종은 연결 후 `/mcp`에서 tools/list로 확인 — 공식 페이지에 전체 목록 미공개)
- 권한 스코프: `library:read` / `saved:read` / `collections:write` / `feedback:write`
- ⚠️ GitHub 저장소 없음 (호스팅 폐쇄형) — 공식 문서: [nicelydone.club/mcp](https://nicelydone.club/mcp),
  [연결 가이드](https://nicelydone.club/help/integrations/mcp)

### 4.3 Refero — 설계 규칙 (무료)

1. `disabledMcpjsonServers`에서 `"refero"` 제거 → 재시작
2. 첫 실행 시 `npx`가 패키지를 자동 다운로드 (수십 초 소요, 1회만)
3. (선택) 키워드 검색 대신 의미 기반 "vibe search"를 쓰려면 `OPENAI_API_KEY` 설정
4. 테스트 요청:
```
Refero로 대시보드 스타일을 검색해서 DESIGN.md 초안을 만들어줘
```
- 공식 저장소: [github.com/fidgetcoding/refero-design-mcp](https://github.com/fidgetcoding/refero-design-mcp)
- 도구 7종: `refero_search` / `refero_get` / `refero_similar` / `refero_list` /
  `refero_facets` / `refero_design_md` / `refero_refresh`
- 검색 결과가 비어 있으면 "Refero 카탈로그를 refresh해줘" (첫 실행 캐시 문제)

### 4.4 Lazyweb — A/B 근거 (부분 무료)

1. lazyweb.com 가입 → MCP 토큰 발급 (무료)
2. `LAZYWEB_MCP_TOKEN` 환경변수 설정 (`.env.example` 참고)
3. `disabledMcpjsonServers`에서 `"lazyweb"` 제거 → 재시작
4. 첫 실행 워크플로우 목록 확인:
```
Lazyweb 워크플로우 목록을 보여줘 — operation list, task_context "first run Lazyweb capabilities"
```
- 무료 계정: 부분 보고서 / Pro: 전체 보고서 + 우선 용량
- 도구 16종 (공식 GitHub [aboul3ata/lazyweb-skill](https://github.com/aboul3ata/lazyweb-skill) 확인):
  `lazyweb_health` / `lazyweb_growth_score` / `lazyweb_growth_report` / `lazyweb_growth_backlog` /
  `lazyweb_search_screens` / `lazyweb_search_flows` / `lazyweb_search_experiments` /
  `lazyweb_agentic_search_finalize` / `lazyweb_products` / `lazyweb_connections` /
  `lazyweb_reports` / `lazyweb_account` / `lazyweb_compare_image` / `lazyweb_find_similar` /
  `lazyweb_list_categories` / `lazyweb_get_workflows`
- 레거시 별칭(사용 중단 예정): `lazyweb_search` / `lazyweb_get_flows` / `lazyweb_search_ab_tests` /
  `lazyweb_generate_report` / `lazyweb_get_report`

### 4.5 InspoAI — 아이콘 SVG (무료 티어)

1. [app.inspoai.io/mcp](https://app.inspoai.io/mcp)에서 무료 API 키 발급 (신용카드 불필요)
2. `INSPOAI_API_KEY` 환경변수 설정
3. `disabledMcpjsonServers`에서 `"inspoai"` 제거 → 재시작
4. 테스트 요청:
```
InspoAI에서 알림 벨 아이콘을 검색해서 깔끔한 아웃라인 스타일 SVG를 보여줘
```
- 도구 3종: `inspoai_search_designs` / 웹 인스퍼레이션 / 아이콘 검색(SVG 반환)
- ⚠️ 공식 GitHub 저장소 없음 (폐쇄형) — 공식 문서: [inspoai.io/mcp](https://www.inspoai.io/mcp)
- 혼동 주의: 오픈소스 "Inspo"([Nutlope/inspo](https://github.com/Nutlope/inspo))와
  "Inspo AI Studio"([inspoai-studio/inspoai-studio](https://github.com/inspoai-studio/inspoai-studio))는 별개 프로젝트

## 5. 자주 막히는 곳

| 증상 | 원인 | 해결 |
|---|---|---|
| OAuth 로그인 후에도 결과가 비어 있음 | 무료 계정 (Mobbin/Nicelydone는 유료 플랜 필요) | Pro 이상 가입 |
| 로그인 창이 안 뜸 | 브라우저/Claude Code 상태 | Claude Code 재시작 → `/mcp`에서 재승인 |
| Mobbin 429 오류 | 60 req/60초 초과 | 요청 간격 조절 |
| Lazyweb 보고서가 비어 있음 | 무료 계정은 부분 보고서 | Pro 업그레이드 |
| Refero 검색 결과 없음 | 첫 실행 카탈로그 캐시 | "Refero 카탈로그 refresh" 요청 |
| InspoAI 실행 안 됨 | `INSPOAI_API_KEY` 미설정 | 키 발급 + 환경변수 설정 후 재시작 |
| npx 첫 실행이 느림 | 패키지 다운로드 | 1회만 기다리면 됨 |

## 6. 한계와 주의사항

- **확인일 2026-10-13 기준** — 화면 수·요금·한도는 서비스 정책에 따라 변동
- **공식 페이지 확인 필요 항목**: Mobbin 설정 JSON 원문, Nicelydone 도구명 8종(12종 중 4종 확인),
  Refero·InspoAI `/mcp` 페이지 본문
- 스크린샷·디자인 데이터는 **참고용** — 저작권 있는 화면의 직접 복제 금지
- OAuth 브라우저 로그인 단계는 자동화 불가 — **사용자가 직접 수행**
- 이 기능은 KOSTAT 업무(PO/OOR/커미션)와 무관한 **선택 기능**입니다.
  사내 실적 대시보드나 제안서 화면을 만들 때만 사용하세요.
