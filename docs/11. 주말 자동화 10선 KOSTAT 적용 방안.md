# 주말 자동화 10선 KOSTAT 적용 방안

> 외부 가이드 「주말에 각잡고 자동화 해야할 10가지 (48시간 스프린트)」를 KOSTAT 해외영업부 업무(JEDEC Tray / T&R / Packing Material 수출, 미국·HK 고객 PO, 공장별 생산·출하, 월간 커미션)에 맞게 재해석한 문서이다.
> 목적: 10개 항목 중 **무엇을 채택·변형·보류할지** 판단 자료와 선택 옵션을 제공한다.

---

## 1. 개요

### 1.1 가이드 요지

| 구분 | 내용 |
|------|------|
| 목표 | 주말 동안 예약 자동화를 세팅해 월요일 07:00부터 메일·업무기록·회의준비가 자동으로 돌아가게 함 |
| 도구 | Claude(Cowork `/schedule`), ChatGPT(Scheduled 탭) — 둘 다 클라우드 실행 |
| 권장 시작 | 10개 전부가 아니라 **01 메일 분류 / 02 업무 기록 / 08 주간 계획** 3개만 먼저 |
| 운영 규칙 | ① 예약 전 수동 1회 실행 ② 침묵 규칙(할 말 없으면 한 줄) ③ 상태 기억 없음(매번 원본 재조회) ④ 5회 연속 미열람 시 삭제 |

### 1.2 도구별 한계 (가이드 기준, 2026년 6월)

| 항목 | Claude | ChatGPT |
|------|--------|---------|
| 예약 주기 | hourly / daily / weekdays / weekly | monthly 포함 |
| 기존 Drive 파일 편집·append | 제한 (새 파일 생성만) | 가능 |
| 로컬 파일 접근 | 가능 (데스크톱) | 불가 |
| 활성 작업 수 | — | Plus ≈ 5개, Pro ≈ 15개 |

→ KOSTAT 업무 파일(미국오더 xlsx, HK PO LIST, OOR, 커미션 RAW DATA)은 **로컬 Excel**이므로 기본적으로 **Claude 쪽이 적합**하다.

## 3. 산출 — KOSTAT용 프롬프트 (채택 4개)

> 공통 규칙: 모든 프롬프트는 상태를 기억하지 않으므로 매번 원본(메일·캘린더·Excel)을 다시 읽는다. 할 말이 없으면 한 줄로 끝낸다.

### 3.1 [01] 평일 07:00 고객사 메일 분류 + 영문 초안

```
평일 오전 7시

지난 24시간(월요일은 금요일 18시 이후) 수신 메일을 분류해줘.

STEP 1 — 분류 (정확히 하나)
급함(오늘 회신) / 회신 필요(2~3일) / 공장 전달 필요 / 참고 / 노이즈
긴급도는 "오늘 회신하지 않으면 출하·생산·PO 확정에 어떤 영향이 있는가"로 판단.

STEP 2 — 영문 답장 초안
급함·회신 필요 메일마다 초안을 작성해 draft로 저장. 절대 발송하지 마.
다음은 초안 금지, 결정 사항 한 줄만 보고:
- 단가 변경·견적·할인 요청
- 품질 클레임 보상, 반품, 크레딧
- 계약·NDA·결제 조건
- 납기 확답 (공장 확인 전)

STEP 3 — 보고 (60초 분량)
오늘 급함: [고객사] — [제목] — [왜 급한지] — 초안: 예/아니오
회신 필요: [고객사] — [제목] — 초안: 예/아니오
공장 전달 필요: [공장] — [내용]
내가 막고 있는 것 / 공장이 막고 있는 것: 오래된 순, 경과 일수 포함
숫자: 총 수신, 급함, 회신 필요, 노이즈

규칙
- 급함·회신 필요가 없으면 "메일함 깨끗함. 노이즈 [X]개."만 답해.
- PO 번호·수량·단가·납기를 지어내지 마. 불명확하면 "확인 필요".
- 보고 전 급함 목록을 재검토해 내일 처리해도 되는 것은 뺀다.
```

### 3.2 [04] 평일 18:00 내일 고객 미팅 브리프

```
평일 오후 6시

내일 캘린더에서 외부 고객사·공장·협력사 미팅만 골라 브리프를 작성해.
내부 정기회의는 제외. 해당 미팅이 없으면 "내일 필요한 브리프 없음."만 답해.

각 브리프 (1페이지)
- 미팅: 제목, 시간, 주최자, 참석자
- 목적: 한 문장. 초대장으로 불명확하면 "아젠다 사전 요청 필요"
- 고객사 현황: 미결 PO 건수·금액, 최근 출하, 납기 임박 건 (미국오더/HK PO LIST 기준)
- 지난 논의: 최근 메일 스레드에서 남은 이슈, 특히 내가 약속하고 아직 이행 안 한 것
- 회사 최근 동향: 최근 60일 공개 뉴스, 출처 링크 필수. 없으면 "공개 정보 없음"
- 질문 3개: 이 고객·이 주제에만 해당하는 질문
- 예상 요구: 단가 인하, 납기 단축, 샘플 등 2~3개와 한 줄 대응
- 목표 결과: 모르면 빈칸

규칙
- 추론은 "(추론)" 표시.
- 단가·조건을 확정 표현으로 쓰지 마. 상사 승인 필요 사항은 "승인 필요"로 표시.
```

### 3.3 [08] 월요일 07:30 주간 영업 브리프

```
월요일 오전 7시 30분

이번 주 영업 브리프를 작성해. (morning-briefing은 "오늘", 이 브리프는 "이번 주")

가져올 것
- 캘린더: 월~금 외부 미팅
- 메일: 지난 14일 중 내가 다음 행동을 해야 하는 스레드
- 미국오더 / HK PO LIST: 이번 주 출하 예정, 납기 7일 이내 미출하 PO
- 지난주 EOD 회고(Notion KPT)의 Problem·Try 항목

작성할 것
- 이번 주 한눈에: 요일별 외부 미팅, 출하 건수, OOR 처리일
- TOP 3: 이번 주 가장 레버리지 큰 일 3개. 이유, 수행 시간대, 밀리면 생기는 비용
- 내가 병목인 것: 고객·공장·상사가 나를 기다리는 건, 경과 일수
- 상사 결정 필요 사항: 옵션 A/B/C를 펼쳐 이 문서에서 결정할 수 있게
- 누락 위험: 마감이 있는데 움직임 없는 약속
- 버릴 것: 이번 주 시간 대비 가치가 낮은 일 1개 이상

규칙
- 3분 안에 읽을 수 있게. 캘린더를 다시 읊지 말고 의미를 말해.
- TOP 3는 가까운 마감 3개가 아니라 방어 가능한 순위.
```

### 3.4 [10] 금요일 16:00 상사 주간 보고서 초안

```
금요일 오후 4시

김인섭 이사 / SM CHO 대표 보고용 주간 보고서 초안을 작성해.

먼저 읽을 것
- 이번 주 EOD 회고 5일치
- 이번 주 신규 PO(미국/HK), 출하 실적, OOR 변동
- 고객사와 주고받은 주요 메일

형식 (개요 → 현황 → 산출/계산 → 종합의견, 별도 권고안 섹션 없음)
- 개요: 이번 주 핵심 한 줄
- 현황: 고객사별 신규 PO·출하·미결, 공장별 이슈
- 산출/계산: 수주 금액, 출하 금액, 전주 대비 증감, 월 누계
- 종합의견: 상사 판단이 필요한 사항과 선택지(옵션 A/B/C), 각 옵션의 영향

규칙
- 숫자는 원본 파일에서만. 없으면 "데이터 없음".
- 가장 근거가 약한 섹션에 [REVIEW] 표시.
- 조용한 주는 짧게. 부풀리지 마.
```

### 4.2 판단 포인트

- 과장 역할(상사 보고 자료, 의사결정 옵션 제공)과 직접 연결되는 항목은 **10 상사 주간 보고**와 **08 주간 브리프의 "상사 결정 필요 사항"**이다.
- 02 업무 기록은 기존 EOD 스킬과 기능이 겹쳐 신규 가치가 작다.
- 01 메일 분류는 효과가 가장 크지만, **회사 메일 계정 형태(2.3 확인사항 1번)**에 따라 옵션 A·B로 할지 C로 할지 결정된다.
- 어느 옵션이든 가이드 규칙대로 **수동 1회 실행 → 결과 수정 → 예약** 순서로 진행하고, 1주 운영 후 5회 연속 미열람 항목은 삭제한다.
