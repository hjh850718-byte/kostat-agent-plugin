# 외부 클로드 스킬 설치 가이드 (find-skills + 추천 8개)

- 출처: 트렌드코어 스킬공유자료실 #068 「클로드 스킬 전체 1위」 (2026-10-31)
- 검증: skills.sh 검색 API 조회 (2026-11-28)
- 설치 대상: 과장님 Windows PC의 Claude Code (전체/글로벌 설치)

---

## 1. find-skills 개요

- 클로드 스킬 중 설치 수 1위(가이드 기준 410만 건)인 스킬이다. 만든 곳은 vercel-labs.
- 하는 일을 말하면 맞는 스킬을 찾아주고, 설치 수와 제작자를 보여준 뒤 고르면 바로 설치까지 해 준다.
- 설치: `npx skills add vercel-labs/skills --skill find-skills -g -a claude-code`
- 검색: `npx skills find <키워드>`
- 설치 후 Claude Code를 재시작하고 `/find-skills`를 입력해 목록에 뜨는지 확인한다.

### 주의할 이름 비슷한 스킬

- `agent-browser`: `101-skills`, `magentosh`, `skills-shell` 같은 다른 제작자가 같은 이름으로 올린 것이 각각 17만~20만 건 있다.
- `grill-me`, `prototype`: 중국어 번역본(`vinvcn/mattpocock-skills-zh-cn`)이 있다.
- 아래 프롬프트는 원본 저장소를 직접 지정하므로 이런 비슷한 스킬이 설치되지 않는다.

### KOSTAT 업무 관련도

| 높음 | agent-browser | 경쟁사 JEDEC Tray/T&R 제품·가격 조사 |

| 낮음 | hyperframes, frontend-design, prototype, web-design-guidelines, design-taste-frontend | 영상·디자인용. 필요할 때만 설치 |

## 3. PC Claude Code에 붙여 넣을 설치 프롬프트

필요 없는 스킬은 해당 줄을 지우고 붙여 넣는다.

```
아래 8개 클로드 스킬을 전체(글로벌)로 설치해 주세요. 내 PC는 Windows입니다.
먼저 `node -v`로 Node.js가 있는지 확인하고, 없으면 설치 방법을 알려 주고 멈춰 주세요.
각 명령을 하나씩 실행하고, 기존 kostat-* 스킬과 이름이 겹치면 멈추고 알려 주세요.

npx skills add vercel-labs/skills --skill find-skills -g -a claude-code
npx skills add mattpocock/skills --skill grill-me -g -a claude-code
npx skills add heygen-com/hyperframes --skill hyperframes -g -a claude-code
npx skills add vercel-labs/agent-browser --skill agent-browser -g -a claude-code
npx skills add mattpocock/skills --skill handoff -g -a claude-code
npx skills add anthropics/skills --skill frontend-design -g -a claude-code
npx skills add mattpocock/skills --skill prototype -g -a claude-code
npx skills add vercel-labs/agent-skills --skill web-design-guidelines -g -a claude-code
npx skills add leonxlnx/taste-skill --skill design-taste-frontend -g -a claude-code

완료되면 설치된 스킬 목록, 설치 경로, 호출 방법(/이름)을 표로 정리하고,
마지막에 "Claude Code를 재시작하세요"라고 알려 주세요.
```

## 5. 참고

- 설치 도구가 "스킬은 전체 권한으로 실행되니 사용 전에 검토하라"고 안내한다. 8개 모두 유명 제작자의 원본이라 위험도는 낮다.
- `npx`를 찾을 수 없다고 나오면 Node.js가 없는 것이다. Claude Code에 "노드 설치해 주세요"라고 말한 뒤 다시 실행한다.
- 설치 수는 매일 바뀐다. 위 숫자는 2026-11-28 조회 기준이다.
