# Qwen3.8-Max 모델 연동 가이드

> **상태**: 🟢 참고 자료 (선택 적용)
> **목적**: `kostat-team.sh`로 실행하는 Claude Code CLI 세션의 기반 모델을 필요 시 Qwen3.8-Max로 교체해 비용을 절감하는 방법을 정리한다.
> **출처**: 트렌드딸깧(@trenddalkak.ai)이 정리한 Qwen 공식 발표 자료(qwen.ai 블로그, 2026.08.03) 요약본을 참고. Qwen/알리바바 공식 문서가 아니므로 세부 스펙·가격은 원문(https://qwen.ai/blog?id=qwen3.8)에서 재확인할 것.

---

## 1. 왜 검토하는가

`kostat-team.sh`는 orchestrator/po-agent/oor-agent/validator 4개 창을 tmux로 띄우고 각 창에서 `claude --dangerously-skip-permissions`를 실행한다(`scripts/kostat-team.sh:27,34,41,48`). 이 방식은 Claude Code CLI가 기본 모델(Claude)로 4개 세션을 동시에 돌리므로, PO 입력·OOR 정리처럼 반복적이고 정형화된 Fan-out 작업이 몰리는 날은 토큰 비용이 누적된다.

Claude Code는 `ANTHROPIC_BASE_URL` / `ANTHROPIC_MODEL` 환경변수로 호출 대상을 OpenAI 호환 엔드포인트로 바꿀 수 있다. 즉 **CLI·스킬·SKILL.md는 그대로 두고, 뒤에서 응답하는 모델만 저렴한 것으로 교체**할 수 있다는 뜻이다. Qwen3.8-Max는 입력 $2 / 출력 $6 (100만 토큰당)로 Claude Opus 5(입력 $5 / 출력 $25) 대비 크게 저렴하면서, 반복적인 다단계 작업(에이전틱 워크플로우) 벤치마크에서 경쟁력 있는 점수를 보인다.

**주의**: 아래 비교는 원문 발표 자료 기준 벤치마크 수치이며, KOSTAT 실제 업무(한글 PO PDF 파싱, Excel 서식 유지, 한준희 과장 개인 문체 재현)에서의 정확도는 검증되지 않았다. 적용 전 반드시 §4의 체크리스트로 자체 검증할 것.

## 2. 언제 쓰면 좋은가 (스킬별 권장)

| 스킬 | 특징 | Qwen 전환 권장 여부 |
|------|------|-------------------|
| kostat-po-update / kostat-hk-po-update | PDF→Excel 정형 입력, Fan-out 반복 작업 | ✅ 권장 — 비용 절감 효과 큼, 출력 포맷이 고정적 |
| kostat-oor-weekly | 표 정렬·컬러코딩·PO# 비교, 규칙 기반 | ✅ 권장 |
| kostat-commission-invoice | 요율 역산 + 검증(Gen/Eval Loop) | ⚠️ 신중 — Eval(검증) 단계는 정확도가 중요하므로 Claude 유지, Gen(생성) 단계만 Qwen 테스트 권장 |
| kostat-eod-retrospective | KPT 회고 요약 | ⚠️ 신중 — 요약 품질/뉘앙스 확인 후 결정 |
| kostat-orchestrator | 트리거 분류·팀 소집 판단 | ❌ 비권장 — 판단 정확도가 전체 흐름에 영향 |
| kostat-about-me 개입 문서(상사 보고, 고객 이메일 번역) | 문체·톤이 중요 | ❌ 비권장 — 원문 벤치마크상 SWE-bench Pro/HLE 등 "한 번에 정답" 유형 과제에서 상대적으로 약함 |

기준: 정형화된 반복 Fan-out 작업은 Qwen으로, 판단·검증·개인 문체가 중요한 작업은 Claude로 유지한다.

## 3. 설정 방법

### 3.1 API 키 발급

1. https://home.qwencloud.com/ 에서 계정 생성 후 `DASHSCOPE_API_KEY` 발급
2. 리전별 Base URL 확인
   - 싱가포르(권장, 한국에서 지연시간 양호): `https://dashscope-intl.aliyuncs.com/apps/anthropic`
   - 베이징: `https://dashscope.aliyuncs.com/compatible-mode/v1`
   - 미국(버지니아): `https://dashscope-us.aliyuncs.com/compatible-mode/v1`

### 3.2 Claude Code CLI 환경변수

```bash
export ANTHROPIC_MODEL="qwen3.8-max"
export ANTHROPIC_SMALL_FAST_MODEL="qwen3.8-max"
export ANTHROPIC_BASE_URL="https://dashscope-intl.aliyuncs.com/apps/anthropic"
export ANTHROPIC_AUTH_TOKEN="<발급받은 DASHSCOPE_API_KEY>"

claude
```

환경변수 4개만 설정하면 Claude Code UI·명령어·플러그인 구조는 그대로 두고 뒤에서 Qwen3.8-Max가 응답한다.

### 3.3 kostat-team.sh 적용

`scripts/kostat-team.sh`는 `KOSTAT_MODEL_ENV` 환경변수가 지정되면 각 tmux 창을 실행하기 전에 해당 env 파일을 source하도록 되어 있다. 예를 들어 PO/OOR 창만 Qwen으로 돌리고 orchestrator/validator는 Claude를 유지하려면, 판단이 필요 없는 창에만 개별적으로 아래처럼 적용한다.

```bash
# ~/.kostat-qwen.env
export ANTHROPIC_MODEL="qwen3.8-max"
export ANTHROPIC_SMALL_FAST_MODEL="qwen3.8-max"
export ANTHROPIC_BASE_URL="https://dashscope-intl.aliyuncs.com/apps/anthropic"
export ANTHROPIC_AUTH_TOKEN="<발급받은 DASHSCOPE_API_KEY>"
```

```bash
KOSTAT_MODEL_ENV=~/.kostat-qwen.env ./scripts/kostat-team.sh
```

`KOSTAT_MODEL_ENV`를 지정하지 않으면 기존과 동일하게 Claude 기본 모델로 4개 창이 실행된다(하위 호환).

### 3.4 추론 깊이 옵션

| 옵션 | 언제 쓰면 좋음 |
|------|---------------|
| xhigh (기본값) | 복잡한 분석, 커미션 요율 역산처럼 깊은 추론이 필요한 작업 |
| medium | 정확도-속도 균형이 필요한 일반 PO/OOR 처리 |
| low | 단순 반복 작업(포맷 정리 등) |

## 4. 전환 전 검증 체크리스트

- [ ] PO PDF 샘플 3건 이상으로 Excel 입력 결과를 Claude 결과와 비교 (금액·PO#·납기일 오차 0건 확인)
- [ ] OOR F열/AS열 정렬, PO# 불일치 표기가 기존과 동일하게 동작하는지 확인
- [ ] 커미션 인보이스는 Eval 단계를 반드시 Claude로 유지한 채 Gen 단계만 테스트
- [ ] 한글 인코딩(EUC-KR/UTF-8 혼용 파일) 깨짐 여부 확인
- [ ] API 키가 `.env`/셸 히스토리에 평문 노출되지 않도록 관리 (Git에 커밋 금지)

## 5. 가격 비교 (원문 발표 기준, 100만 토큰당)

| 모델 | 입력 | 출력 |
|------|------|------|
| Qwen3.8-Max | $2 | $6 |
| Qwen3.7-Max (직전 세대) | $2.5 | $7.5 |
| Claude Opus 5 | $5 | $25 |

캐시된 입력은 $0.25, 명시적 캐시 재사용 시 $0.17까지 낮아진다(원문 기준). KOSTAT 플러그인은 반복 프롬프트(SKILL.md, references/*.md)가 많아 캐시 재사용 비중이 높은 편이므로 실제 절감폭은 워크로드에 따라 달라진다.

## 6. 원복 방법

`ANTHROPIC_BASE_URL` / `ANTHROPIC_MODEL` / `ANTHROPIC_SMALL_FAST_MODEL` / `ANTHROPIC_AUTH_TOKEN` 환경변수를 unset하거나 새 셸을 열면 Claude Code는 기본 Claude 모델로 즉시 되돌아간다. `kostat-team.sh`는 `KOSTAT_MODEL_ENV`를 지정하지 않은 기본 실행이 원상태이므로 별도 원복 작업이 필요 없다.
